# Django Admin and Project Structure

## Django Admin and `manage.py` Commands

Django provides command-line tools for creating and managing projects and applications.

Two important command-line tools are:

- `django-admin`
- `manage.py`

A simple way to remember them:

**django-admin = build the house**  
**manage.py = manage the house**

---
