# Django Development Environment Setup

This document records the local development environment used for the Meta Back-End Developer Professional Certificate.

## Software

- Windows 11
- Python 3.12
- Django 6.0.7
- Git
- Git Bash
- Visual Studio Code

## Initial Setup

```bash
py -m venv env
source env/Scripts/activate
py -m pip install --upgrade pip
py -m pip install django
```

## Verify Installation

```bash
python --version
py -m django --version
py -m pip list
```
